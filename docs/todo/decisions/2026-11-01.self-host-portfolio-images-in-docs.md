# Self-host portfolio images in docs/portfolio/img/ instead of hotlinking the blog

## Context
The blog has screenshots for DCProof and toolstud.io.

## Options considered
- Copy locally: self-hosted and stable, with lightbox
- Hotlink: no files in the repo, but breaks if the blog changes
- No images: plainer pages

## Decision
Self-host portfolio images in docs/portfolio/img/ instead of hotlinking the blog

## Consequences
Image updates on the blog aren't picked up automatically. Replace the files in `docs/portfolio/img/` by hand.
