# Keep the Pages custom domain www.forret.com that the user set before the DNS switch

## Context
The PRP said to set the Pages custom domain only after DNS pointed to GitHub, to avoid a redirect to a domain still pointing at toolstud.io.

## Options considered
- Remove the cname until DNS is switched (spec)
- Leave the user's setting and switch DNS (done)

## Decision
Keep the Pages custom domain www.forret.com that the user set before the DNS switch

## Consequences
The custom domain and HTTPS are configured in the Pages settings, not via a CNAME file. Don't add `docs/CNAME`.
