# Put the generated-file marker after the front matter in opensource.md

## Context
The PRP said to start `opensource.md` with a `<!-- generated by … -->` comment.

## Options considered
- Comment on line 1 (spec): breaks front matter parsing
- Comment right after the front matter (done): front matter is still recognised

## Decision
Put the generated-file marker after the front matter in opensource.md

## Consequences
Any generated Markdown in `docs/` must start with front matter. Markers go after it.
