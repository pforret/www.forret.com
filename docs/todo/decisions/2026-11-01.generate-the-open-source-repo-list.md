# Generate the open-source repo list with scripts/portfolio_repos.sh using gh api and jq

## Context
Star counts and descriptions change. A hand-written list would go stale.

## Options considered
- Generator script: stays current and repeatable, but needs gh + jq and a script to maintain
- Static Markdown: no tooling, but goes stale

## Decision
Generate the open-source repo list with scripts/portfolio_repos.sh using gh api and jq

## Consequences
`docs/portfolio/opensource.md` is generated and must not be edited by hand. Rerun the script before a publishing build.
