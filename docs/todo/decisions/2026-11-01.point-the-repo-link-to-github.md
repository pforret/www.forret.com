# Point the repo link to GitHub pforret/www.forret.com

## Context
There was no `repo_url`, and the repo icon was Bitbucket, although the code is on GitHub.

## Options considered
- GitHub repo link with the GitHub icon
- No repo link at all: hides that the site is open

## Decision
Point the repo link to GitHub pforret/www.forret.com

## Consequences
The header shows the repo with its star and fork counts. If the repo is renamed, update `repo_url` and `repo_name`.
