# Use cv.forret.com as the content source for About; LinkedIn is only linked

## Context
LinkedIn blocks automated fetching (HTTP 999); cv.forret.com has the full CV.

## Options considered
- cv.forret.com (chosen): fetchable and complete
- A LinkedIn data export or PDF: needs manual work by the user

## Decision
Use cv.forret.com as the content source for About; LinkedIn is only linked

## Consequences
If the CV changes, update it from cv.forret.com. LinkedIn content (recommendations, skills) isn't used.
