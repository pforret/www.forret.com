# Deploy only through pages.yml; the GitHub-created static.yml was removed

## Context
The user had created `.github/workflows/static.yml` on GitHub, which deploys on every push, next to the planned `pages.yml`.

## Options considered
- Keep both: double deploys
- Keep static.yml: deploys on every push, old action versions
- Keep pages.yml (done): only on site/** changes, current versions

## Decision
Deploy only through pages.yml; the GitHub-created static.yml was removed

## Consequences
One Pages workflow only. Don't re-create static.yml from the GitHub UI template.
