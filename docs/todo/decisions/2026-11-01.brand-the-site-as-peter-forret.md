# Brand the site as Peter Forret, tech consultant and entrepreneur

## Context
The scaffold name "www.forret Docs by pforret" showed up in every title and in the OG and Twitter previews.

## Options considered
- "Peter Forret": personal brand, matches the domain
- "forret.com": domain as brand, less personal
- "Peter Forret · founder & tech consultant": a role in every title, but long

## Decision
Brand the site as Peter Forret, tech consultant and entrepreneur

## Consequences
All titles and link previews read "Peter Forret". The description mentions DCProof, toolstud.io and the Bash tools, so update it when the focus changes.
