# Lay out the portfolio as a card overview with detail pages per flagship and a separate open-source page

## Context
The portfolio mixes a few major projects with a long list of small tools.

## Options considered
- Overview + detail pages + opensource.md: room for project detail, a clean overview
- A single page: simpler, but long and shallow

## Decision
Lay out the portfolio as a card overview with detail pages per flagship and a separate open-source page

## Consequences
New flagship projects get their own page in `docs/portfolio/` and a card in `index.md`, and must be added to `nav` in `zensical.toml`.
