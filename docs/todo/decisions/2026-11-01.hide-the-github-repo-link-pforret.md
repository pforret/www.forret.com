# Hide the GitHub repo link (pforret/www.forret.com) from the header

## Context
The user asked to hide the pforret/www.forret.com link shown in the header.

## Options considered
- Keep `repo_url`/`repo_name` (planned): shows the repo with star and fork counts
- Remove them (chosen): a cleaner header; the code repo isn't promoted

## Decision
Hide the GitHub repo link (pforret/www.forret.com) from the header

## Consequences
No `repo_url`/`repo_name` in `zensical.toml`. `theme.icon.repo` stays but is unused. GitHub is still linked from the footer social links.
