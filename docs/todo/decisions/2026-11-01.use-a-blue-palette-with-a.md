# Use a blue palette with a light/dark toggle that follows the OS

## Context
The red scaffold palette clashed with the blue "pf" favicon taken from blog.forret.com.

## Options considered
- Blue + dark toggle: matches the favicon and the blog, respects the OS preference
- Blue, light only: simpler
- Red + toggle: clashes with the favicon

## Decision
Use a blue palette with a light/dark toggle that follows the OS

## Consequences
Two `[[project.theme.palette]]` entries. Custom CSS has to work in both the `default` and `slate` schemes.
