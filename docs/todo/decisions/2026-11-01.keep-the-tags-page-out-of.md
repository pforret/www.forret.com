# Keep the Tags page out of the navigation menu

## Context
The user asked to hide the Tags page from the menu.

## Options considered
- Tags as a tab: a visible tag index
- Out of the nav (chosen): the page is still built at `/tags/` and reachable through tag links

## Decision
Keep the Tags page out of the navigation menu

## Consequences
`tags.md` isn't listed in `nav`, and a comment in `zensical.toml` explains why. Don't add it back when regenerating the nav.
