# Publish the site on www.forret.com as GitHub Pages custom domain

## Context
The site needs a public URL once GitHub Pages is set up. `www.forret.com` currently CNAMEs to `redirect.toolstud.io`, and DNS is at Gandi. `site_url` drives the sitemap, RSS feeds, social cards and llms.txt.

## Options considered
- `www.forret.com` as a custom domain: one CNAME change, keeps the familiar address, but replaces the toolstud.io redirect
- apex `forret.com`: needs 4 A records to GitHub IPs, plus www → apex; more DNS work
- `pforret.github.io/www.forret.com` for now: no DNS change, but a subpath URL that would have to change later

## Decision
Publish the site on www.forret.com as GitHub Pages custom domain

## Consequences
`site_url = "https://www.forret.com/"`. The custom domain is set in the Pages settings (with Actions deploys, a `CNAME` file in `site/` is ignored). Until DNS is switched, the github.io URL serves pages whose canonical and sitemap links point to www.forret.com.
