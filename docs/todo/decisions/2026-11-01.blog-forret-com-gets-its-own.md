# blog.forret.com gets its own portfolio page, separate from the Blog tab

## Context
This site already has its own Blog tab (docs/blog/, blog plugin). The older external blog.forret.com needed a place that doesn't get confused with it.

## Options considered
- Own portfolio page docs/portfolio/blog.md, with a card and nav entry after bashew
- A short block on docs/blog/index.md: fewer files, but that index is generated by the blog plugin

## Decision
blog.forret.com gets its own portfolio page, separate from the Blog tab

## Consequences
The page is titled "blog.forret.com", never "Blog". docs/blog/ is not touched. A new page also means a line in the hand-tuned nav in zensical.toml.
