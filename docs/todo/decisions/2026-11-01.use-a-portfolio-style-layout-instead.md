# Use a portfolio-style layout instead of the docs-style feature set

## Context
The scaffold features (integrated sidebar TOC, autohiding header, copy-page button) suit documentation, not a personal portfolio.

## Options considered
- Portfolio-style: section index pages, back-to-top, prev/next footer, right-hand TOC, header always visible
- Minimal change: only add top and footer
- Keep the docs style

## Decision
Use a portfolio-style layout instead of the docs-style feature set

## Consequences
`portfolio/index.md` acts as the section page via `navigation.indexes`. The TOC appears on the right. No announcement bar (`announce.dismiss` removed).
