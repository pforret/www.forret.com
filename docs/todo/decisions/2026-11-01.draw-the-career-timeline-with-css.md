# Draw the career timeline with CSS in extra.css instead of Mermaid

## Context
The career overview needs a visual timeline that fits the vintage editorial theme.

## Options considered
- Editorial CSS timeline (chosen): matches the theme, no JS, readable in llms.txt
- Mermaid timeline: quick, but generic and JS-rendered

## Decision
Draw the career timeline with CSS in extra.css instead of Mermaid

## Consequences
The timeline is a Markdown list inside `<div class="timeline" markdown>`. Styles live in the `/* ---- timeline ---- */` block of `extra.css` and must work in both schemes.
