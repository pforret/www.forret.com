# Use a vintage editorial look (cream, ink, warm brown; Fraunces, Work Sans, JetBrains Mono) instead of the blue palette

## Context
While implementing the config item, the user asked to use https://designmd.app/library/vintage-editorial as design inspiration.

## Options considered
- Blue Material palette (planned): matches the favicon, no custom CSS
- Vintage editorial via `docs/stylesheets/extra.css` with `primary/accent = "custom"` (chosen): a distinctive typography-led brand, but more CSS to maintain

## Decision
Use a vintage editorial look (cream, ink, warm brown; Fraunces, Work Sans, JetBrains Mono) instead of the blue palette

## Consequences
Colours live in `docs/stylesheets/extra.css` as CSS variables for both `default` and `slate`. The design is light-only, but the dark toggle was kept with an inverted ink/cream variant. The blue "pf" favicon now contrasts with the warm palette. Some theme variables (the footer ones) are overridden by the palette CSS and must be set on the elements themselves.
