# Show all non-fork, non-archived GitHub repos with at least 5 stars, grouped by theme

## Context
The GitHub profile has 208 public repos, far too many to list. The portfolio needs a selection rule.

## Options considered
- ≥ 5★, grouped by theme: an objective cut-off, about 27 repos, no hand-curation
- Hand-picked ~12: a tighter story, but needs ongoing curation
- ≥ 10★ only: about 10 repos, but drops recent work (PeakClaude, mkdox, splashmark)

## Decision
Show all non-fork, non-archived GitHub repos with at least 5 stars, grouped by theme

## Consequences
The list grows by itself as repos gain stars. The theme map in the generator has to be kept up to date, and unmapped repos land in "Other".
