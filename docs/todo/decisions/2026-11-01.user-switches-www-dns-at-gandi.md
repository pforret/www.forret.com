# User switches www DNS at Gandi only after the github.io deploy works

## Context
Moving `www.forret.com` to GitHub Pages is outward-facing: it replaces the current toolstud.io redirect. The DNS change happens at Gandi, outside this repo.

## Options considered
- The user changes DNS after the github.io deploy is shown to work: safe, and nothing goes live on the domain unverified
- Change DNS immediately: fewer steps, but a broken deploy would take the domain down

## Decision
User switches www DNS at Gandi only after the github.io deploy works

## Consequences
The agent never touches DNS or the Pages `cname` setting before the switch. Setting `cname` early would make the github.io URL redirect to a domain that still points to toolstud.io. After the switch: `gh api -X PUT repos/pforret/www.forret.com/pages -f cname=www.forret.com`, then enforce HTTPS.
