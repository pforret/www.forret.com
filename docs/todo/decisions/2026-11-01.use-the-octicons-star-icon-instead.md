# Use the octicons star icon instead of the star emoji in the generated repo list

## Context
`scripts/portfolio_repos.sh` printed `:star:` (a coloured twemoji), and the editorial design says no emoji in the UI.

## Options considered
- `:star:` emoji (original)
- `:octicons-star-16:` line icon (done)

## Decision
Use the octicons star icon instead of the star emoji in the generated repo list

## Consequences
Generated or hand-written pages should use `:material-…:`/`:octicons-…:` icons, not emoji.
