# Use cookieless Simple Analytics without a cookie banner

## Context
The scaffold showed a cookie banner for an empty custom analytics partial.

## Options considered
- No analytics, no banner: simplest
- Cloudflare Web Analytics: cookieless, needs a token
- Plausible/Umami: cookieless, needs an account
- Google Analytics + banner: needs consent
- Simple Analytics (user's choice): cookieless, no banner

## Decision
Use cookieless Simple Analytics without a cookie banner

## Consequences
The script lives in `docs/overrides/partials/integrations/analytics/custom.html` with `provider = "custom"`. The domain must be added in the Simple Analytics dashboard. Don't self-host the script through the privacy plugin.
