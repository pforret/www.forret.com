# List DCProof as Peter's own company (Founder) on the CV

## Context

## Options considered
- DCProof as a Brightfish product: changes the portfolio role
- DCProof as own company, a separate CV entry (chosen)
- Leave the CV as cv.forret.com: inconsistent with the portfolio

## Decision

## Consequences
