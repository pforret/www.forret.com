# blog.forret.com portfolio page uses a screenshot header image

## Context
The other flagship portfolio pages have a header image (img/dcproof.png, img/toolstudio.jpg); bashew.md does not.

## Options considered
- shot-scraper screenshot saved as docs/portfolio/img/blog.jpg, the same pattern as toolstudio
- No image, like bashew.md

## Decision
blog.forret.com portfolio page uses a screenshot header image

## Consequences
The screenshot gets outdated when the blog's design changes, so retake it then. Check it for cookie banners or a half-loaded page before using it.
