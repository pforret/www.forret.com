# Keep build helper scripts in scripts/ at the repo root, outside docs/

## Context
The generator script must not end up in `site/`.

## Options considered
- `scripts/` at the root: never published
- Inside `docs/` with `exclude_docs`: works, but mixes tooling with content

## Decision
Keep build helper scripts in scripts/ at the repo root, outside docs/

## Consequences
Any future helper scripts also go in `scripts/`.
