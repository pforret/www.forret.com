# Show LinkedIn, GitHub, blog, X and YouTube as footer social links

## Context
A personal site needs contact and profile links. blog.forret.com/social lists many profiles.

## Options considered
- A subset: LinkedIn, GitHub, blog, X, YouTube (chosen)
- Everything from /social (Instagram, Threads, Product Hunt, …): cluttered

## Decision
Show LinkedIn, GitHub, blog, X and YouTube as footer social links

## Consequences
LinkedIn uses /in/peterforret (the URL the user gave), not /in/pforret as on the blog. Change the links in `[[project.extra.social]]`.
