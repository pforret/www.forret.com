# Give the home page its own front matter with a personal description

## Context
The PRP only asked for an intro text on the home page.

## Options considered
- Intro text only (spec): the meta description falls back to the site default
- Front matter with `title: Home` and a personal `description` (done)

## Decision
Give the home page its own front matter with a personal description

## Consequences
The home page meta description and OG description now come from `docs/index.md`. Keep it in sync with `site_description`.
