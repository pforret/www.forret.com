# Use Fraunces for text, Work Sans for UI and JetBrains Mono for code

## Context
The PRP kept the scaffold font (Nunito); the vintage editorial design asks for Fraunces, Work Sans and JetBrains Mono.

## Options considered
- Keep Nunito (spec): no change
- Fraunces (text) + JetBrains Mono (code) via `theme.font`, Work Sans via `@import` in `extra.css` (done)

## Decision
Use Fraunces for text, Work Sans for UI and JetBrains Mono for code

## Consequences
All three are self-hosted by the privacy plugin. UI chrome selectors in `extra.css` use `--ed-ui-font` (Work Sans).
