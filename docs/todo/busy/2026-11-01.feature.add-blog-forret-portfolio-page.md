## PRP

### Goal
A new portfolio page at `/portfolio/blog/` presents Peter's personal blog blog.forret.com (2004–now):
a header screenshot, a short intro, three AI/tech quotes from the blog with links to their posts, and
a curated "Most read" list of 10 posts with full titles and URLs. The page has a card on the
Portfolio overview and an entry in the Portfolio navigation, right after bashew.

### Why
- The blog is Peter's longest-running project (22 years). It's linked from About, CV, timeline and
  the social icons, but the portfolio doesn't present it.
- The quotes show his current AI/software thinking; the most-read list shows range (photography,
  tango, tech how-tos, side projects).
- It also separates the old external blog from this site's own Blog tab (`docs/blog/`).

### Decisions taken
- Which quotes → only the AI/tech ones: (a) Mythical Agent-Month TL;DR, (b) its "force multiplier"
  sentence, (d) the PrintThatVideo question. No tagline epigraph, no "send me a link" (user) (recorded: decisions/2026-11-01.blog-forret-com-portfolio-page-shows.md)
- Which posts in "Most read" → curated top 10: leave out the joke posts "Top Ten Smelly Celebrities"
  and "Size doesn't matter" (user). "Govern yourselves accordingly" (#9, a reprinted legal-threat
  email) is also left out under that rule, and "The Mythical Agent-Month" (#12) takes its place
  because the quotes come from it (default, rationale: curated + ties into the quotes) (recorded: decisions/2026-11-01.blog-forret-com-most-read-list.md)
- View counts → not shown, and the list isn't ranked by numbers: an ordered list in the order
  below (default)
- Header image → shot-scraper screenshot of blog.forret.com, `docs/portfolio/img/blog.jpg` (user) (recorded: decisions/2026-11-01.blog-forret-com-portfolio-page-uses.md)
- Placement → `docs/portfolio/blog.md` titled "blog.forret.com", card on `portfolio/index.md`, nav
  entry after `portfolio/bashew.md` and before `portfolio/opensource.md` (user) (recorded: decisions/2026-11-01.blog-forret-com-gets-its-own.md)

### Known gotchas & guardrails
- Mirror the existing patterns named under Context; do not introduce new ones for this item
- CRITICAL: never run `mkdox2 build` to verify: it commits and pushes, which publishes the site. Use the plain `docker run … build` from CLAUDE.md
- PRESERVE: the `# hand-tuned:` comments and every other entry in `zensical.toml`; only add one line to the Portfolio `nav` list
- Don't confuse this with the site's own Blog tab (`docs/blog/`, blog plugin): don't touch `docs/blog/` and don't name the page "Blog" in nav or H1; use "blog.forret.com"
- Quotes are real published text: don't paraphrase or "improve" them. Typographic apostrophes are OK
- Don't link any post from the omitted list (celebrities, size, govern yourselves)
- Image: save as JPEG with width ≤ 1600 px like `img/toolstudio.jpg` (e.g. `shot-scraper https://blog.forret.com/ -o /tmp/… --width 1280 --height 800`, then convert to jpg with `sips -s format jpeg`); check it by viewing it
- `site/` is regenerated by the test build: that's expected. Don't commit (the user commits)

### Validation loop (executable, in order)
```bash
# Level 1 — build (no commit)
docker run --platform linux/amd64 --rm -v "$PWD":/docs pforret/mkdox-zensical build 2>&1 | grep -iE "warn|error" ; echo "build exit: ${PIPESTATUS[0]}"   # expect exit 0, no warnings about portfolio/blog
# Level 2 — page content
test -f site/portfolio/blog/index.html && echo page-ok
grep -c 'blog.forret.com/20' site/portfolio/blog/index.html          # expect ≥ 12 (10 list links + quote links)
grep -c '<blockquote' site/portfolio/blog/index.html                  # expect 3
grep -iE 'smelly|size-doesnt|govern-yourselves' site/portfolio/blog/index.html || echo omitted-ok
grep -o 'portfolio/blog/' site/portfolio/index.html | head -1          # card links to the page
grep -o 'href="[^"]*portfolio/blog/"' site/index.html | head -1        # nav entry present
test -f site/portfolio/img/blog.jpg && echo img-ok
# Level 3 — links live
grep -o 'https://blog.forret.com/[^"]*' docs/portfolio/blog.md | sort -u | while read u; do echo "$(curl -s -o /dev/null -w '%{http_code}' "$u") $u"; done   # all 200
# Manual: `mkdox2 serve` (or the user's running preview) → Portfolio tab shows "blog.forret.com" after bashew; page renders in light and dark mode
```
