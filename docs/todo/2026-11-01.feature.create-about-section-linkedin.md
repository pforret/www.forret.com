# Create about section from LinkedIn profile

## Request
create a about section with https://www.linkedin.com/in/peterforret/

## Analysis
This is a new feature. `docs/about/index.md` exists but only holds the heading "About this site". The `about/` tab is already in place, and `zensical.toml` already includes `about/*.md` in the `llmstxt` "Docs" section, so new pages there are picked up automatically. The site's stated goal is a CV and a career overview, and this section is where they belong.

The source is a problem: **LinkedIn can't be fetched automatically.** It returned HTTP 999 (bot block, login wall). The profile content has to come another way:
- a LinkedIn data export (Settings → Data privacy → Get a copy of your data, which gives `Profile.csv`, `Positions.csv`, `Education.csv`, `Skills.csv`), or
- the profile saved as PDF (Profile → More → Save to PDF), or
- the text pasted in by hand.
Possible extra sources: the blog's About page (`https://blog.forret.com/about/`) and the GitHub profile README.

Open questions:
- Which input will be provided: the data export, the PDF or pasted text?
- How should it be split: a single About page, or About (bio) + CV (positions, education, skills) + Career (narrative timeline)?
- Personal details: show only a contact or LinkedIn link, or more (e-mail, location)? Leave out phone numbers.
- Should the career timeline be a Mermaid `timeline` diagram (Mermaid fences are already enabled)?
- Does this overlap with the portfolio item (`2026-11-01.feature.create-portfolio-section.md`)? Projects should live in the portfolio, and the CV should link to them.

## Impacted files
- `docs/about/index.md`: replace the placeholder with a bio (headline, summary, photo, links to LinkedIn, GitHub and the blog)
- `docs/about/cv.md`: positions, education and skills, as a structured CV
- `docs/about/career.md`: career overview or timeline (narrative, optionally a Mermaid timeline)
- `docs/about/.pages`: page order within the About tab
- `docs/index.md`: link to About from the home page (the home page is still scaffold text)

## Plan
1. Get the profile content (export, PDF or paste; see the open questions). Convert a PDF with the pdf-to-markdown skill, or read the CSV export directly.
2. Optionally add the blog About page via WebFetch.
3. Write `docs/about/index.md`: bio, headline and links.
4. Write `docs/about/cv.md`: positions in reverse chronological order (company, role, dates, short description), then education and skills.
5. Write `docs/about/career.md`: a career narrative and timeline.
6. Add `.pages` ordering and link it from the home page.
7. Build with `docker run --platform linux/amd64 --rm -v "$PWD":/docs pforret/mkdox-zensical build` (this doesn't commit) and check `site/about/`.

## Acceptance criteria
- The About tab shows a real bio instead of "About this site".
- The CV lists all positions from the LinkedIn profile with company, role and dates, plus education and skills.
- A career overview page gives the timeline at a glance.
- The pages link to LinkedIn, GitHub and the blog.
- The build finishes with "No issues found" and has no broken internal links.
