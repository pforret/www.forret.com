**Innovating cinema advertising technology since 2006.**

I'm Peter Forret: CTO, software architect and entrepreneur. I take products from product management and software architecture all the way to implementation. Today I'm Technical Director at Brightfish, and in 2026 I started building [DCProof](<https://www.forret.com/portfolio/dcproof/index.md>).

## A.I. first, since 2024

For the last two years, A.I. has been at the heart of almost everything I build:

- **A.I. for software development:** I work with A.I. coding agents (Claude Code) every day: they write, run and fix code with me. One example: record a browser task once, and Claude Code turns it into a tested Playwright script exposed as an API.
- **A.I. for media processing:** at Brightfish I build A.I.-assisted applications for news analysis, media processing and admissions forecasting. With DCProof, video, speech and language models rate a trailer or ad for Kijkwijzer, FSK, BBFC and MPAA in one pass, and explain every rating.
